      Note 01EssayVerification

      Verification is part of the work.

      Most errors from language models are not reasoning failures. They are unchecked steps. A system that verifies before it reports looks slower and is faster overall.

      Read note

      We treat verification as a pipeline stage with its own tools: re-running tests after a patch, re-fetching a source to confirm a quote, checking that extracted fields point to the clause they came from.

      The rule is simple. If a step can be checked cheaply, it gets checked. If it cannot, the result says so. That second half matters more than it sounds: a clearly marked uncertainty is useful, a confident guess is a liability.

      This note describes a design principle. It does not report measured results.

      Note 02EssayContext

      Context is a budget, not a bucket.

      Bigger context windows invite a lazy habit: put everything in. Quality drops when the signal gets diluted. ANGRA decides what enters context and what stays in memory.

      Read note

      Every token in context competes for attention. Long tasks accumulate tool output, logs and dead ends. Left alone, the useful parts get buried.

      So context is managed: summaries replace raw logs, finished branches collapse to their result, and retrieved passages carry their source so they can be dropped and re-fetched later instead of carried forever.

      Design principle, not a benchmark claim.

      Note 03EssayRelease

      Why the public instance is small on purpose.

      The full ANGRA system is not public. What you can reach here is a narrow slice, connected to a backend we choose, with limits we can explain.

      Read note

      Oblivion builds software and AI systems with its own AI. Opening that system fully would mean opening tools, memory and infrastructure that are not designed for anonymous use.

      Instead, Public Instance 01 exposes conversation, and, when connected, research and agent modes with visible tool states. Tools, software and future models may be released over time. A local or GGUF release is possible in the future; nothing is available until it is announced on this page.

          09FAQ · Contact§ END OF MAP

          Questions

          Is this the full ANGRA system?

          No. Public Instance 01 is a small public-facing slice. The main ANGRA system is not publicly available.

          Can I download ANGRA? Is there a GGUF?

          Not today. A local or GGUF release is possible in the future. Nothing exists until it is officially announced in the News log above. Any other download claiming to be ANGRA is not from Oblivion.

          Does the instance browse the web?

          Only when connected to a research backend that does. The page itself cannot fetch the web, and without that backend research mode says so instead of pretending.

          Which model powers it?

          Whatever model the connected backend runs. The chat shows a model name only if the backend reports one. It never guesses.

          Where are my chats stored?

          In your browser's local storage. Messages are sent only to the backend endpoint configured on this page. Export or delete them any time.

          Are the diagrams live data?

          No. Every visualization is labeled Simulation, Conceptual or Experimental. The inspector's frame rate and viewport are the only live measurements, and they come from your browser.

          Can I connect LM Studio or Bionic?

          Yes. Both expose OpenAI-compatible chat endpoints. Use the presets in the Backend panel, set the endpoint, and keep any keys on a server-side proxy.
